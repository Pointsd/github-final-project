# Simple Interest Calculator

## Project Title
**Simple Interest Calculator** — Final Project for the *Introduction to Git and GitHub* course (IBM Developer Skills Network).

## Project Details
This project is a command-line **Simple Interest Calculator** written as a Bash script. It takes user input for the principal amount, the rate of interest, and the time period, and then calculates the simple interest.

The formula used is:

```
Simple Interest = (Principal × Rate × Time) / 100
```

## Features
- Interactive command-line input
- Calculates simple interest based on three input fields: principal amount, rate of interest, and time period
- Lightweight Bash implementation

## How to Run
```bash
bash simple-interest.sh
```
